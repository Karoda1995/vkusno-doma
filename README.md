# Вкусно Дома

Адаптивный сайт рецептов на HTML, CSS и JavaScript без сборки и внешних зависимостей.

Логотип открывает каталог. В рецептах есть пересчёт ингредиентов на 1–20 порций и отметка выполненных шагов. Избранное, калории, картинки в шагах и подписи внизу удалены.

## Добавление рецептов

В каталоге нажмите «Добавить рецепт». Укажите название, описание, время, базовое количество порций, ингредиенты и шаги. Фото JPG, PNG или WebP до 1 МБ необязательно. Каждый шаг записывается с новой строки, заголовок и описание можно разделить символом `|`. Пустое количество ингредиента позволяет указать «по вкусу».

Рецепты и фотографии сохраняются в localStorage текущего браузера. Они остаются после перезагрузки, но не синхронизируются между устройствами и не публикуются другим посетителям. Очистка данных браузера удаляет добавленные рецепты. При недоступном или заполненном хранилище форма показывает ошибку и сохраняет введённые поля.

## Запуск

Выполните `python3 -m http.server 4174` и откройте http://localhost:4174.
