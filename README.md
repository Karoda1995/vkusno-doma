# Вкусно Дома

Адаптивный сайт рецептов на HTML, CSS и JavaScript без сборки и внешних зависимостей.

Логотип открывает каталог. В рецептах есть пропорциональный пересчёт ингредиентов и дробных порций и отметка выполненных шагов. Избранное, калории, картинки в шагах и подписи внизу удалены.

## Добавление рецептов

В каталоге нажмите «Добавить рецепт». Укажите название, описание, время, кухню, тип блюда, ингредиенты и шаги. Количество ингредиентов указывается для всего блюда. Вес и порции оцениваются автоматически с учётом единиц измерения и типа блюда. Если количества основных ингредиентов не хватает, можно указать известный вес готового блюда. Фото JPG, PNG или WebP до 1 МБ необязательно. Каждый шаг добавляется кнопкой «Добавить шаг» и содержит отдельные обязательные поля заголовка и описания. Шаги можно удалять; номера обновляются автоматически. Выберите одну единицу измерения. Для «по вкусу» количество не требуется.

После подключения серверных ключей рецепты и фотографии автоматически сохраняются в GitHub через сервер Cloudflare. При первом добавлении сайт запрашивает пароль автора; вход действует до 24 часов. Успех отображается только после подтверждения GitHub. При ошибке поля остаются в форме. Локальная копия сохраняется дополнительно, когда хранилище браузера доступно.

## Параметры и пересчёт

Скорость определяется автоматически: до 30 минут включительно — «Быстро», от 31 до 60 — «Среднее время», более 60 — «Долго». Кухня и тип блюда выбираются в форме и отображаются в рецепте.

Количество любого числового ингредиента можно изменить прямо в карточке рецепта. Все остальные количества и порции пересчитываются по исходным пропорциям, без изменения сохранённого рецепта. Например, 400 г муки и 100 г соли на 4 порции → 320 г муки и 80 г соли на 3,2 порции. Ввод поддерживает точку и запятую; «по вкусу» остаётся без пересчёта. Кнопки порций также работают с дробными значениями. Минимум — 0,01 порции; значения отображаются до трёх знаков после запятой.

Ранее сохранённые рецепты сохраняют своё базовое число порций и шаги.

## Автоматическое хранение

Сервер: https://vkusno-doma-recipes.karodaa.workers.dev

Настройка ключей описана в backend/README.md. GITHUB_TOKEN остаётся в зашифрованных секретах Cloudflare. Публичный адрес сервера задан в site-config.js. Сервер создаёт отдельный JSON в data/recipes; GitHub Actions обновляет общий каталог и публикует сайт. Публикация занимает некоторое время после сохранения.

«Супер Борщик» уже сохранён в репозитории. Ранее добавленные локальные рецепты продолжают читаться из браузера.

Количество ингредиента указывается в одной выбранной единице: шт., г, мл, кг, л, ч.л., ст.л. или «по вкусу». Для «по вкусу» количество не требуется. Картинка необязательна: можно оставить подбор по названию, выбрать «Без картинки», использовать библиотеку или загрузить свою. Загруженная картинка уменьшается до 128 × 128.

## Оценка выхода блюда

Ориентиры на порцию: основные блюда и супы — 400 г, завтраки — 350 г, салаты и напитки — 250 г, гарниры — 200 г, закуски и десерты — 150 г, выпечка — 100 г, соусы — 50 г. Это настройки сайта для приблизительной оценки, а не нормы питания. Ложки считаются без горки (5 и 15 мл), штучные продукты — по среднему весу. Сухие макароны учитываются с условным увеличением массы в 2,5 раза; другие ингредиенты — по исходному весу. Уваривание, испарение и впитывание зависят от приготовления. Указанный вручную вес готового блюда имеет приоритет.

Пересчёт меняет базовое количество порций, сохраняя исходные количества ингредиентов. При неполных данных существующий рецепт сохраняет прежнее количество порций.

Справочные источники для перевода объёма в вес и поведения макарон: https://www.kingarthurbaking.com/learn/ingredient-weight-chart и https://www.barilla.com/en-us/help-with/pasta-kitchen-tips/pasta-serving-size . Коэффициенты и размеры порций в portion-estimator.js — приближённые продуктовые допущения.

## Каталог ингредиентов

В каталоге рецептов кнопка «Каталог ингредиентов» открывает библиотеку из 61 продукта в семи группах. Доступны поиск по названию и фильтр по группе. При создании рецепта названия подсказываются, а картинки подбираются автоматически; в выборе картинки продукты сгруппированы. Режим «Без картинки» и загрузка своего изображения сохранены. Все готовые миниатюры — отдельные JPEG 128 × 128. Источник библиотеки — ingredient-catalog.js.

Рецепт карбонары удалён; старые ссылки открывают каталог, локальные копии этого рецепта не возвращаются в список.
