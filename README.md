# Вкусно Дома

Адаптивный сайт рецептов по референсам для компьютера и телефона. HTML, CSS и JavaScript без сборки и внешних зависимостей.

В первой версии: карбонара, пересчёт ингредиентов на 1–20 порций, избранное на устройстве, поиск в каталоге и отметка выполненных шагов. Каталог содержит один стартовый рецепт. Учётные записи и серверная база данных не подключены.

## Запуск

В папке проекта выполните `python3 -m http.server 4173` и откройте http://localhost:4173.

## GitHub Pages

Создайте репозиторий `vkusno-doma`, загрузите проект в ветку `main`. В Settings → Pages выберите Source: GitHub Actions. Workflow `Deploy to GitHub Pages` публикует сайт после каждого обновления `main`.

## Изображения

Фото блюда создано для этого проекта. Изображения ингредиентов и шагов показаны из предоставленного пользователем референса через CSS. Для дальнейшего расширения каталога желательно заменить их отдельными фотографиями.
