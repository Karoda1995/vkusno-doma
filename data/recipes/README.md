# Рецепты

Загрузите сюда JSON-файл, который сайт подготовил кнопкой «Сохранить в GitHub».
После подтверждения Commit changes рецепт появится на всех устройствах.
Файлы содержат рецепт и его фотографии. Не удаляйте старые файлы без резервной копии.

Не помещайте сюда пароли или токены: репозиторий публичный.
